OpenRouter and OpenCode Usage History (wss-openrouter)

Weekly point-in-time captures of OpenRouter's task mix, session economics, benchmarks, model catalogue and provider directory, plus OpenCode's usage telemetry: model and lab shares, session cost, cache ratio, retention and geography. Captured because the publishers do not archive the windows these endpoints expose.

History held: 2026-09-01 to 2026-10-27.

Findings

Figures are rebuilt from the derived tables on every run; each one names the entities it is about so it can be acted on without a further query.

Using it

Derived tables are CSV under data/ in the repository; the bytes they came from are under raw/, and SOURCES.md lists every source URL.

Every observation carries source_id and raw_ref. The matching manifest row holds that raw_ref with the URL, the fetch timestamp and a SHA-256 of exactly what came back, so any number here traces to the bytes it came from.

Cite this dataset by its repository and the date you took it from: https://github.com/q3dresearch/wss-openrouter, accessed 2026-10-27.

Repository code and captured data are licensed separately. This dataset offers no onward licence: the capture adds a timestamp and a parse, neither of which creates a right over the underlying values. Each publisher's own terms govern their material and are listed per source above. Generated by wss datapage — do not edit by hand.
